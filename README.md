## MCP bridges

Live-model access for agents inside the tools you already run.

- [jgs-magic-sysmlv1-mcp](https://github.com/jgsystemsconsulting/jgs-magic-sysmlv1-mcp) - Air-gapped bridge so Claude Code and other agents read and drive live SysML v1 models in CATIA Magic through 130+ tools, without cloud export. Free, Pro, and Enterprise tiers.
- [jgs-archi-mcp](https://github.com/jgsystemsconsulting/jgs-archi-mcp) - Eclipse plugin that exposes ArchiMate models in Archi over MCP so agents can query, analyse, and edit EA models in natural language.
- [jgs-sysmlv2-api-mcp](https://github.com/jgsystemsconsulting/jgs-sysmlv2-api-mcp) - MCP server for the OMG SysML v2 REST API: 35 tools for navigate, version, and author flows with staged, token-confirmed commits.

## Agent skills

Skills that drive the bridges or stand alone in your coding agent.

- [jgs-archi-skills](https://github.com/jgsystemsconsulting/jgs-archi-skills) - Orchestrator plus specialist skills for ArchiMate modelling in Archi, driving the JGS Archi Bridge MCP across Claude Code, Cursor, Gemini CLI, Codex, Copilot, and ZCode.
- [jgs-magic-sysmlv1-read-skills](https://github.com/jgsystemsconsulting/jgs-magic-sysmlv1-read-skills) - Eighteen free, read-only SysML v1 analysis skills for CATIA Magic (MSOSA) over the jgs-magic-sysmlv1-mcp bridge via /jgs-v1.
- [jgs-goal-spec](https://github.com/jgsystemsconsulting/jgs-goal-spec) - Tool-agnostic Claude Code skills that turn a rough idea into a hardened engineering spec: goal-formatter to goal-spec to spec-review.
- [jgs-lit-memory](https://github.com/jgsystemsconsulting/jgs-lit-memory) - One skill that captures academic papers into a git-tracked literature corpus with a citation graph and offline inbox, inside each project.

## The awesome-mbse list family

The reference lists behind MBSE practice, curated and dated.

- [awesome-mbse](https://github.com/jgsystemsconsulting/awesome-mbse) - The family flagship: a curated, vetted, dated index of Model-Based Systems Engineering covering SysML v1/v2, methods, tools, and openable models.
- [awesome-sysml-v2](https://github.com/jgsystemsconsulting/awesome-sysml-v2) - OMG SysML v2 tools, example models, and learning resources in one maintained list.
- [awesome-requirements-engineering](https://github.com/jgsystemsconsulting/awesome-requirements-engineering) - Standards, methods, interchange formats, tools, books, and community for requirements engineering.
- [awesome-magicgrid-mbse](https://github.com/jgsystemsconsulting/awesome-magicgrid-mbse) - MagicGrid MBSE methods, tools, and learning materials.
- [awesome-enterprise-architect](https://github.com/jgsystemsconsulting/awesome-enterprise-architect) - Sparx Systems Enterprise Architect product resources for MBSE practitioners.
- [awesome-capella](https://github.com/jgsystemsconsulting/awesome-capella) - Capella and Arcadia: methods, models, and learning paths in one list.
- [awesome-archimate](https://github.com/jgsystemsconsulting/awesome-archimate) - ArchiMate resources for enterprise architecture and MBSE work.
- [awesome-stpa](https://github.com/jgsystemsconsulting/awesome-stpa) - STAMP/STPA and hazard analysis resources for safety and systems engineering.
- [awesome-digital-engineering](https://github.com/jgsystemsconsulting/awesome-digital-engineering) - Digital engineering, digital thread, and model-based definition resources.
- [awesome-mbse-community](https://github.com/jgsystemsconsulting/awesome-mbse-community) - People and organizations behind free and open systems-engineering and MBSE knowledge.
